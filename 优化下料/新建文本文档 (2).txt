读取一个json文件，文件的格式如下
{
  "cut_pieces": [
    {
      "value": 556.2,
      "count": 2
    },
    {
      "value": 556.5,
      "count": 218
    },
  ],
  "stocks": [
    {
      "value": 9600.0,
      "count": 58,
      "is_spray": false
    },
    {
      "value": 6000.0,
      "count": 168,
      "is_spray": false
    }
  ]
}
cut_pieces：是下料单，value代表下料的长度，count代表需要该长度的数量
stocks：是提料单（也是原材的信息），value代表原材的长度，count代表该原材的数量

实现一个算法，算法的目的是通过提料单中的原材切割出下料单中的所有材料。该算法中可变参数有锯缝和料头长度以及是否是喷涂材料, 锯缝是切割过程中，每次下刀对原材料的损耗。料头长度是需要去除原材料两端的长度，是否喷涂材料标记，true代表是喷涂材料，false是普通材料

先判断是否是喷涂材料：喷涂材料需要在对原材料下料前，先按照初始化时确定的料头长度平均分配到左右两端进行去除。比如料头初始化时为20，锯缝损耗是5，原材料是6000。那么进行下料时，先去除左右两端的10的料头，以及去除料头时5的锯缝损耗，然后对5970的原材进行最大利用率切割所需的下料长度。

如果材料是普通的材料：那么优先考虑该原材料可以切割出下料单中哪些规格的子长度和数量，在考虑的过程中要考虑两个子长度间的锯缝的损耗，在保证原材利用率最大的情况下也要保证下料的所有长度和锯缝不能超过原材长度。如果下料的规格的数量总和刚好等于原材长度，这样单根原材的利用率最高也是最优方案；
如果切除一部分子长度后，还有剩余的材料。那么考虑左右两端去除料头的情况，如果剩余的材料多，去除了料头以及去除料头时产生的锯缝，则再剩下的原材为余料。
